# v2 外部工具适配器

本文记录已实现的宿主服务与兼容范围；设置中的可信工具绑定、当前媒体输入确认与导出选择器已接入。运行时不会查找 PATH、下载或自动启用工具。

## 支持配置

| 动作 | 已锁定适配版本 | 输入、输出与限制 |
|---|---|---|
| LosslessSlice | FFmpeg / FFprobe 8.0.1 | 单次 MediaInput + ExportGrant；固定流拷贝到 Matroska/MP4/WebM，宿主用 FFprobe 读取实际包时间范围。 |
| ExtractAudio | FFmpeg 8.0.1 | 单个音轨，单声道 16/48 kHz PCM；原始 PCM 经管道返回，宿主生成带准确长度的 WAV。 |
| Transcribe | whisper.cpp 1.8.2 | 上一步 WAV（最大 64 MiB）、宿主批准模型与语言；CPU 4 线程，最大 600 秒；宿主生成 WebVTT。 |
| ResolveMetadata | yt-dlp 2025.11.12 | 单个公网 HTTP(S) URL，120 秒；任务专属带随机凭证代理，返回经过重新授权及字段筛选的 JSON 产物。 |

宿主批准记录固定主程序、所需动态库/数据文件、模型的 SHA-256；调用前再次校验路径身份与摘要。版本号字符串不证明程序可信。Windows yt-dlp 使用可逐文件固定的 `yt-dlp_win.zip` 目录发布，不接受自解压单文件配置。whisper.cpp 此版本没有 CLI 版本查询，版本依据为宿主核验的发布摘要。

命令由宿主构造；插件没有参数数组、可执行路径、环境变量、滤镜、脚本或配置目录字段。无 Shell；Windows 通过启动属性把子进程直接纳入 JobObject，仅继承指定管道，其他平台使用独立进程组。环境重建为空 PATH 和私有 HOME/临时目录。子进程树、标准输入/输出/错误均有取消及超时，stderr 总量上限 1 MiB，产物计入磁盘账本。该约束依赖用户批准的工具及适配版本，不是针对恶意本机二进制的 OS 沙箱。

yt-dlp 禁用配置、扩展插件、JS 运行时、远程组件、缓存和后处理；首版不支持需要这些能力的网站。`--no-netrc` 不是该版本的合法开关，隔离 HOME 且不启用 netrc。代理逐 CONNECT/HTTP 请求验证授权、DNS 和实际地址；HTTPS 由工具到站点端到端验证，不能检查隧道里的应用内容。该版本的正常 HTTP 请求路径遵循指定代理；没有系统防火墙隔离保证。代理不接收私有 Origin 授权；系统 DNS 返回特殊用途/代理 fake-IP 地址时拒绝，不能通过放行该地址恢复播放。

## 文件、结果和取消

- 输入能力只能由宿主针对用户选择的实际文件发放，绑定安装身份、控制窗口/媒体/context 代次、动作与 5 分钟期限，消费一次。拒绝符号链接、重解析点和多硬链接，持有已打开文件并检查身份/大小/修改时间；Windows 禁止其他进程同时写入或删除。
- FFmpeg/FFprobe 通过有界回环 Range 中继读取文件；不接收文件路径。允许的输入解复用器不包含播放列表，MOV 外部数据引用保持该固定版本的禁用默认值。
- Artifact 句柄绑定实例和完整代次，`ArtifactRead {handle, offset, len}` 每次最多 1 MiB，完成交付 Blob 和 EOF。未交付的产物由宿主回收。跨身份、关闭后、切集或控制上下文撤销后使用返回陈旧句柄错误；普通播放 seek 只撤销流读取，不撤销同窗口的工具/目录任务。
- ExportGrant 默认只创建新文件。后台在同目录暂存、同步数据，再用 create-if-absent 硬链接原子提交；文件系统不支持该操作则报错，不改用覆盖式重命名。源文件不写入。临时名清理失败继续持有磁盘与句柄配额，由后台重试。
- 原子创建目标是不可撤销的提交点：在此之前取消不产生最终文件；并发取消若发生在提交之后，已导出的用户文件保留，即使完成事件因代次变化被丢弃。UI 应据宿主导出审计显示已提交结果，不能把取消说明为回滚文件。
- 切片返回 `requested_start_ms/end_ms` 十进制非负整数字符串，以及 `actual_start_ms/end_ms` 有符号十进制毫秒字符串。实际范围按可展示包的 PTS/时长计算，可能偏离请求边界，不承诺逐帧精确；无法确定最终时长时报 Unsupported，不虚构结果。
- 当前媒体哈希只处理宿主选定文件。全文件 MD5/SHA-256 按块运行并检查取消/文件变化；SparseSha256V1 对 `iris-sparse-sha256-v1\0`、LE64 文件大小、去重排序的首/中/尾至多 1 MiB 窗口（各含 LE64 偏移、长度、内容）计算 SHA-256，不用于完整文件一致性证明。
